1.1 Overview of a Runtime1.1 Overview of a Runtime

Runtime = JavaScript Engine + Environment-provided APIsRuntime = JavaScript Engine + Environment-provided APIs

If JavaScript is the "programming language," then the runtime is the "operating system" — it determines what your code can and cannot do.If JavaScript is the "programming language," then the runtime is the "operating system" — it determines what your code can and cannot do.

CODE

An analogy: JavaScript is "Mandarin," the runtime is the "city"An analogy: JavaScript is "Mandarin," the runtime is the "city"

  • JavaScript syntax (Mandarin) is the same everywhereJavaScript syntax (Mandarin) is the same everywhere

  • Browser = has DOM, window, fetch (like a city with malls, libraries)Browser = has DOM, window, fetch (like a city with malls, libraries)
  • Node.js = has fs, http, path (like a city with factories, highways)Node.js = has fs, http, path (like a city with factories, highways)
